Арман, Гравитациялық архитектор ретінде танымал, FAIO ғарыш станциясында тұрақты гравитациялық өріс құру мәселесіне тап болды. Ол үшін оған гравитациялық өрістердің өзара әрекеттесу матрицаларын есептеу қажет. Бұл есептеу көп еңбекті қажет етеді, сондықтан ол кеңістіктік тұрақтандыру технигі Руниден көмек сұрауға шешім қабылдады. Олар әртүрлі гравитациялық параметрлерді білдіретін екі матрицаның көбейтіндісін табуды жоспарлап отыр.

Енгізу барысында үш натурал сан a a a, b b b және c c c беріледі, мұндағы a a a және b b b – бірінші матрицаның жолдары мен бағандарының саны, ал b b b және c c c – екінші матрицаның жолдары мен бағандарының саны. Содан кейін a a a жол енгізіледі, олардың әрқайсысында бірінші матрицаның мәндерін білдіретін b b b нақты сандары бар.

Содан кейін b b b жол енгізіледі, олардың әрқайсысында екінші матрицаның мәндерін білдіретін c c c нақты сандары бар.

Рунидің станциядағы гравитациялық процестерді дұрыс тұрақтандыруы үшін бірінші матрицаны екінші матрицаға көбейту нәтижесін шығару қажет.

Шектеулер:

  • Матрицаларды дұрыс көбейту үшін бірінші матрицаның бағандарының саны екінші матрицаның жолдарының санына сәйкес келуі керек: b b b.

  • Матрицалардың өлшемдеріне қойылатын шектеулер: 1 ≤ a , b , c ≤ 300 1 \leq a, b, c \leq 300 1≤a,b,c≤300.

Көбейтінді нәтижесі Арман мен Руниге тұрақты жасанды гравитацияға қол жеткізуге және олардың миссиясын сәтті аяқтауға көмектеседі.

Шығару форматы: Матрицалардың көбейтіндісі a a a жол түрінде берілуі керек, олардың әрқайсысында c c c нақты сандары бос орындармен бөлінген.
