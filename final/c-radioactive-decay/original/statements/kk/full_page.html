Кіріспе

Физикадан белгілі болғандай, радиоактивті элементтер әр T 0 T_0 T0​ секунд сайын өз белсенділігінің (массасының) жартысын жоғалтады. Бұл процессті төмендегі теңдеумен сипаттауға болады:

m ( t ) = m 0 ( 1 2 ) t / T 0 m(t) = m_0 \left(\frac{1}{2}\right)^{t / T_0} m(t)=m0​(21​)t/T0​

Сізге эксперимент нәтижелері берілген. Олар n n n жұп t t t уақыт пен m ( t ) m(t) m(t) масса мәндерінен тұрады. Сіздің міндетіңіз – жартылай ыдырау кезеңін T 0 T_0 T0​ табу.

Бұл есепті шығару үшін әртүрлі эвристикалық әдістерді немесе мәліметтерді алдын ала түрлендіріп, классикалық сызықтық регрессия әдісін қолдануға болады.

Сызықтық регрессия

Сызықтық тәуелділігі бар { ( x i , y i ) } i = 0 n \{(x_i, y_i)\}_{i=0}^n {(xi​,yi​)}i=0n​ мәліметтер жиынтығын қарастырайық. Осы жиынтықтағы әрбір ( x i x_i xi​, y i y_i yi​) жұпты сызықтық функция y i = a x i + b y_i = ax_i+b yi​=axi​+b арқылы сипаттай аламыз. Мұндағы a a a, b b b белгісіз сызықтық функцияның параметрлері.

Сызықтық функцияның параметрлерін әр нүктенің түзуден орташа квадраттық ауытқуын минимизациялау арқылы анықтауға болады:

L ( a , b ) = 1 n ∑ i = 0 n ( f ( x i ) − y i ) 2 = 1 n ∑ i = 0 n ( a x i + b − y i ) 2 → min ⁡ L(a, b) = \frac{1}{n}\sum_{i=0}^n\left(f(x_i) - y_i\right)^2 = \frac{1}{n}\sum_{i=0}^n\left(ax_i+b - y_i\right)^2 \rightarrow \min L(a,b)=n1​i=0∑n​(f(xi​)−yi​)2=n1​i=0∑n​(axi​+b−yi​)2→min

∂ ∂ a L ( a , b ) = 0 \frac{\partial}{\partial a}L(a, b) = 0 ∂a∂​L(a,b)=0 және ∂ ∂ b L ( a , b ) = 0 \frac{\partial}{\partial b}L(a, b) = 0 ∂b∂​L(a,b)=0 теңдеулерін шешу арқылы аналитикалық жолмен белгісіз мәндерді табуға болады.

Бағалау критерийі

Егер сіздің болжамыңыз дұрыс жауаптың 1% шегінде болса, сіз 100 ұпай аласыз. Егер жіберілген болжам мен дұрыс жауаптың арасындағы қате 5% артық болса, онда 0 ұпай беріледі. Қорытынды балл барлық тест жиынтықтары үшін орташа балл ретінде есептеледі.
