Welcome to the finals of the Fizmat AI Olympiad 2024. Its six problems move from pen-and-paper statistics to classic machine-learning algorithms you implement from scratch — outlier detection, regression, clustering, text classification, and a support vector machine. Solve them in any order; each task is scored independently. Good luck.

- **A — Math Test Results.** Recompute a class's average and a minimum retake score after two students are added — a short statistics exercise answered with two numbers.
- **B — The story of a meteorologist.** Implement the interquartile-range (IQR) method to find and output the outliers in a year of ice-purity readings.
- **C — Radioactive decay.** From noisy (mass, time) measurements, estimate a substance's half-life — a regression after log-linearization.
- **D — Kmeans.** Implement k-means clustering from fixed points and fixed initial centroids, minimizing the within-cluster distance.
- **E — Text Classification.** Assign each Medium article one of 95 tags using keyword matching built from a training set.
- **F — SVM.** Fit a linear support vector machine: output the separating line that classifies 2D labelled points with the maximum margin.
