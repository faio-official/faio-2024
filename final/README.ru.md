Добро пожаловать на финал Fizmat AI Olympiad 2024. Его шесть задач ведут от статистики «на бумаге» к классическим алгоритмам машинного обучения, которые вы реализуете с нуля, — поиск выбросов, регрессия, кластеризация, классификация текстов и метод опорных векторов. Решать можно в любом порядке; каждая задача оценивается отдельно. Удачи.

- **A — Результаты теста по математике.** Пересчитайте средний балл класса и минимальный балл пересдачи после добавления двух учеников — короткая задача по статистике с ответом из двух чисел.
- **B — История одного метеоролога.** Реализуйте метод межквартильного размаха (IQR), чтобы найти и вывести выбросы в данных о чистоте льда за год.
- **C — Радиоактивный распад.** По зашумлённым измерениям (масса, время) оцените период полураспада вещества — регрессия после логарифмической линеаризации.
- **D — Kmeans.** Реализуйте кластеризацию k-средних по фиксированным точкам и фиксированным начальным центроидам, минимизируя внутрикластерное расстояние.
- **E — Классификация статей.** Присвойте каждой статье с Medium один из 95 тегов с помощью сопоставления по ключевым словам, построенным из обучающего набора.
- **F — SVM.** Постройте линейный метод опорных векторов: выведите разделяющую прямую, которая классифицирует 2D-точки с метками с максимальным зазором.
