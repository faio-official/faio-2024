Результаты теста по математике

В классе из 30 учеников провели тест по математике. Результаты распределились следующим образом:

  • Средний балл (среднее арифметическое) теста составил — 75.

  • Медианный балл теста — 78.

  • Стандартное отклонение баллов — 5.

Позже к результатам добавили ещё двух учеников, каждый из которых получил 90 баллов. На основе новой информации ответьте на следующие вопросы:

  1. Какой стал новый средний балл? Введите число с точностью до двух знаков после запятой.

  2. После добавления двух учеников медианный балл теста остался равным 78. Учитель объявил, что любой ученик, чей балл превышает медианный на величину нового стандартного отклонения, получит особую похвалу. Дархан, который изначально получил 78 баллов, хочет получить эту похвалу. Ему разрешено пересдать тест один раз, чтобы улучшить свой результат. Какой минимальный балл должен получить Дархан при пересдаче, чтобы получить похвалу? Введите целое число.

Стандартное отклонение — это мера разброса данных относительно их среднего значения. Оно показывает, насколько элементы набора данных отклоняются от среднего значения в среднем.

  • σ \sigma σ — стандартное отклонение, мера разброса данных относительно их среднего значения.

  • N N N — общее количество элементов в наборе данных.

  • x i x_i xi​ — i i i-й элемент набора данных.

  • μ \mu μ — среднее значение набора данных.

Медиана — это значение, которое делит упорядоченный набор данных на две равные части: половина значений меньше или равна медиане, а другая половина больше или равна ей.
